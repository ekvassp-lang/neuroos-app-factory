# Каталог релизов — `/releases/`

Этот каталог — точка сборки артефактов релизов фабрики приложений (STAGE 5, см. `docs/IMPLEMENTATION_ROADMAP.md` и `docs/ARTIFACT_REGISTRY.md`).

## Назначение

- Сюда складываются итоговые артефакты сборки: установщики (nsis/msi/app/dmg/appimage/deb/rpm), APK/IPA (после STAGE 6), контрольные суммы SHA-256, манифесты релиза.
- Каждый артефакт регистрируется через API (`POST /api/v1/artifacts`) с SHA-256 — расхождение хэша отклоняется с ошибкой 409.
- Каталог связан с воротами: **G5** требует артефактов `installer` + `checksum`, **G6** — релиз-нотов и полного набора критериев приёмки.

## Структура

```
releases/
  <project-slug>/
    <version>/
      installer-<platform>.<ext>
      checksums-sha256.txt
      release-notes.md
```

## Каналы

| Канал   | Назначение                                   | Доступ                       |
|---------|----------------------------------------------|------------------------------|
| stable  | Проверенные релизы, утверждённые через G6    | всем пользователям           |
| beta    | Предрелизы, G5 пройден, G6 ожидает владельца | ограниченному кругу          |
| alpha   | Внутренние сборки, артефакты без ворот       | только команде               |
| dev     | Ночные/экспериментальные сборки              | только разработчикам         |

## Автоматическая сборка

Матрица десктоп-сборок описана в `.github/workflows/desktop.yml` (Tauri 2):

- **windows-latest** → nsis, msi
- **macos-latest** → app, dmg
- **ubuntu-latest** → appimage, deb, rpm

Запуск: вручную (`workflow_dispatch`) или по тегу `v*`. Релиз создаётся черновиком — публикация только после подтверждения G6 владельцем. Это правило соответствует §11: без утверждённого G6 статус RELEASED запрещён.

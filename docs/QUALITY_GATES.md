# QUALITY_GATES — NEUROOS APP FACTORY

Версия: 0.1.0 · Статус: PROPOSED → на утверждение (GATE 1)

Каждый Gate содержит: критерии, проверяемые результаты, список подтверждающих артефактов,
ответственного за приёмку, статус. Автоматическое утверждение критических этапов только
на основании ответа ИИ запрещено («Промпт 1» §7).

## Правила работы Gates

1. Gate не может быть approved, пока связанные пункты этапа не в DONE с артефактами
   (Приложение A стандарта).
2. Статусы пунктов: DONE / PARTIAL / BLOCKED / NOT IMPLEMENTED / NOT TESTED — проставляются
   только по фактическим проверкам (NO FAKE SUCCESS).
3. Отказ Gate (rejected) возвращает проект в предыдущее состояние с записью причины.
4. История решений Gates — append-only (lifecycle_event + audit_log).
